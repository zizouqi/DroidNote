安卓续航与流畅度的核心矛盾在于 **即时推送通知** 与 **后台唤醒功耗** 之间的平衡。

## 分类设置后台策略

| 应用类别 | 推荐后台策略 | 原因 |
| --- | --- | --- |
| 即时通讯 / 日历 / 闹钟 | 允许后台运行 / 锁定卡片 | 保证消息送达与定时提醒不丢失 |
| 网盘 / 播放器 / 导航 | 按需后台或前台服务 | 使用期间保活，平时不驻留 |
| 购物 / 外卖 / 资讯 | 严格限制后台 / 禁止自启 | 减少无意义唤醒与关联启动 |

## 关注关键耗电指标

- **5G 与弱信号**：长期处于电梯、地下室等弱信号区域时，基带持续搜索信号会大幅增加功耗；Wi-Fi 环境稳定时可按需使用 4G 或开启系统智能 5G。
- **高刷新率与分辨率**：常规浏览与阅读场景开自适应刷新率即可平衡观感与功耗。
- **定位与蓝牙扫描**：在系统定位设置中关闭不需要的“WLAN 扫描”和“蓝牙扫描”（若无需室内高频定位）。
