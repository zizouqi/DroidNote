闪存（UFS）在剩余空间低于 10%–15% 时，垃圾回收（GC）与写入性能会明显下降，进而导致系统整体卡顿。

## 有效清理的正确姿势

- **预留安全空间**：尽量保持至少 **15% 或 20GB 以上** 的可用存储空间。
- **识别真正占用大户**：使用内置文件管理或专用存储分析工具（如 SD Maid SE / DiskUsage 等）查看 `Android/data`、社交软件缓存与离线媒体目录。
- **聊天软件专项减负**：微信、Telegram、QQ 等长期使用容易累积数 GB 至数十 GB 的媒体与缩略图缓存，建议定期在应用内做“清理缓存 / 管理聊天文件”。
- **少用第三方“一键加速清理”**：频繁强清所有应用缓存会导致应用重启后重新下载和重建索引，反而更耗电且更卡。

{{< callout type="info" >}}
如果升级大版本或使用超过两年后觉得系统明显冗余，提前做好完整备份并执行一次“恢复出厂设置 + 仅恢复必要数据”，往往比各种清理软件更彻底。
{{< /callout >}}
