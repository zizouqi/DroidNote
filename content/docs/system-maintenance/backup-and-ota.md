数据无价。任何系统大版本升级、维修送检或折腾系统修改前，都必须保证至少有一份脱离本机的可用备份。

## 3-2-1 个人备份思路

- **照片与视频**：本地 NAS / 电脑定期同步 + 加密云盘冷备，避免仅依赖单机相册。
- **聊天记录与双因素验证（2FA）**：微信/QQ 使用电脑端迁移或本地备份；TOTP 验证器（如 Aegis / 2FAS / Ente Auth）务必单独导出加密备份并妥善保管密码。
- **应用清单与配置**：记录常用应用清单，系统内置备份工具或开源工具（如 Swift Backup，适合 Root 环境）可保存本地 APK 与设置。

## OTA 系统更新前检查

1. 确保电量在 **50% 以上**，可用存储充足。
2. 若设备曾经 Root 或修改过 `boot` / `init_boot` / 系统分区，**切勿直接点击增量 OTA 重启**，应先还原官方镜像或按对应 Root 方案的“保留 Root 安装 OTA”流程操作。
3. 大版本跨代升级（如 Android 15 → Android 16）建议在有完整备份的前提下进行，升级完成后插电息屏静置一段时间以完成 ART 编译优化（dexopt）。
