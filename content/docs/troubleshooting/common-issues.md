## 异常耗电与发热定位

1. **检查系统电池排行**：先看过去 24 小时软件耗电与硬件（屏幕、移动网络、信号弱）占比。
2. **刚升级系统后的短暂发热**：大版本更新或应用批量更新后，系统会进行后台编译优化与索引重建，通常插电息屏静置 1–2 小时后会恢复正常。
3. **检查唤醒锁（Wakelock）**：若息屏掉电过快（如每小时超过 2%–3%），使用 ADB 导出电池统计信息辅助定位：

```bash
adb shell dumpsys batterystats > batterystats.txt
```

## 联网异常排查清单

- 确认是否开启了残留的代理 / VPN 配置或过期的 **私人 DNS（Private DNS）** 主机名。
- Wi-Fi 显示“已连接但无互联网”时，检查局域网路由器 DHCP、时间同步（系统时间偏差过大会导致 HTTPS 证书校验失败）。
- 国内环境部分软件打不开时，先切换至移动数据测试以排除本地 Wi-Fi / DNS 污染问题。
