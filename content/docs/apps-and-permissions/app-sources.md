尽量避免从搜索引擎随意下载来源不明的 APK。推荐按优先级选择以下分发渠道：

## 推荐渠道分级

1. **系统自带应用商店 / Google Play**：基础商业软件首选，具备基础签名校验与安全审查。
2. **F-Droid / Droid-ify**：开源软件仓库，所有收录应用均由源码可复现构建，适合工具类与日常基础软件。
3. **Obtainium**：直接追踪 GitHub Releases、GitLab、F-Droid 等官方发布源自动检查更新，避免第三方搬运站滞后或夹带广告。

## 安装包安全核查

- 仅对明确需要侧载的工具开启对应安装器的“允许安装未知应用”权限，日常可保持关闭。
- 对于关键开源工具（如密钥管理器、Root 管理器、网络工具），更新前核对发布页面 SHA-256 校验值或开发者的签名指纹。
