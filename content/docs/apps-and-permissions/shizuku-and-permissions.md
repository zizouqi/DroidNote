很多高级管理能力并不需要解锁 Bootloader 或 Root。通过 **Shizuku**（借助无线调试或 ADB 启动的轻量系统 API 代理服务），即可安全完成大量精细化管理。

## 最小权限原则

- **位置 / 相机 / 麦克风**：默认选择“仅在使用该应用时允许”，且按需关闭“精确位置”。
- **读取应用列表 / 剪贴板**：国产应用常高频读取剪贴板与已安装应用列表，建议在系统隐私权限中设为“仅在前台允许”或“拒绝/返回空白”。
- **相册访问**：Android 14+ 支持“仅允许访问选定照片”，发图场景优先选用，无需开放整个媒体库权限。

## Shizuku 常见配合工具

- **Hail（雹） / Ice Box（冰箱）**：在免 Root 状态下安全冻结低频使用但后台流氓的软件，需要时一键解冻启动。
- **App Ops**：比原生系统设置更细粒度地控制单个应用的传感器、后台行为、剪贴板、自启动等隐藏权限项。
- **Install with Options / 杂项工具**：支持降级安装、授权绕过部分安装限制（需谨慎确认包来源）。

{{< callout type="info" >}}
使用无线调试启动 Shizuku 后，每次重启手机需要重新激活一次；只要手机未重启，日常可关闭无线调试开关（部分系统会随之停止 Shizuku，视 ROM 策略而定）。
{{< /callout >}}
