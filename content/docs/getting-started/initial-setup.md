国内主流定制 ROM 与海外原生系统在首次开机时都会开启较多推荐服务、体验计划和个性化广告。建议在安装常用软件前先集中梳理一轮。

## 必检设置清单

{{% steps %}}

### 关闭系统级广告与用户体验计划

在系统设置中搜索以下关键词并逐项关闭：
- **个性化广告推荐 / 广告服务**：关闭“个性化推荐”“商业推广”等开关，并重置广告标识符（OAID）。
- **用户体验改进计划 / 诊断数据**：如无需向厂商上传日志，可关闭自动上传诊断信息。
- **锁屏画报 / 负一屏资讯 / 全局搜索热词**：在桌面与锁屏设置中精简不需要的内容卡片。

### 清理预装可卸载应用

优先通过系统应用列表卸载不需要的第三方预装软件；对于无法直接卸载但确实不使用的内置软件，可先仅做“禁用/停用”，不要盲目使用 ADB 强删未知系统包。

### 配置隐私与网络基础项

- **私人 DNS（Private DNS）**：在网络与互联网设置中按需配置加密 DNS（DoT），减少明文 DNS 劫持。
- **MAC 地址随机化**：连接公共 Wi-Fi 时保持“使用随机 MAC”，家庭或需要固定 IP 的路由器再单独切换为设备 MAC。

{{% /steps %}}

{{< callout type="warning" >}}
不要在未确认作用前批量复制网上的“一键精简脚本”。部分系统服务（如推送通道、框架组件、相册/权限控制器依赖）被移除后，可能引发掉推送、设置闪退甚至 OTA 失败。
{{< /callout >}}
